# Privacy and Data Boundary

This public edition must process only fictional demonstration data.

Not included:

- production mail, attachments or mailbox state;
- real study, site, investigator or user information;
- credentials, cookies, API tokens or certificates;
- internal domains, addresses, machine names or user paths;
- job history, audit logs, screenshots, browser profiles or databases.

If you evaluate the code locally, use reserved example domains and disposable development accounts. Do not upload operational workbooks to issues or pull requests.
