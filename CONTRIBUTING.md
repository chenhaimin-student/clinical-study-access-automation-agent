# Contributing

Contributions should improve the public, generic demonstration without reintroducing private operational details.

1. Create a focused branch.
2. Use fictional data and reserved example domains.
3. Do not add credentials, real mail, workbooks, endpoints, logs or customer identifiers.
4. Run `python tests/self_test.py`.
5. Run `ruff check --select E9,F63,F7,F82 .`.
6. Explain behavioral and safety-boundary changes in the pull request.

By submitting a contribution, you agree that it is licensed under the repository's Portfolio Source-Available License 1.0.
